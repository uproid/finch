# نصب

Finch یک فریم‌ورک وب سمت سرور برای دارت است. این صفحه پیش‌نیازها و مراحل نصب آن را پوشش می‌دهد.

## پیش‌نیازها

- **دارت SDK** — فینچ نیازمند دارت ۳.x یا بالاتر است. از [dart.dev/get-dart](https://dart.dev/get-dart) دانلود کنید.
- یک ترمینال و ویرایشگر متن (VS Code با افزونه Dart توصیه می‌شود).

## نصب Finch CLI

Finch CLI ابزارهای قالب‌بندی پروژه، build، سرویس، و مدیریت مهاجرت را فراهم می‌کند.

```bash
dart pub global activate finch
```

پس از فعال‌سازی، صحت نصب را تأیید کنید:

```bash
finch --version
```

## ساخت پروژه جدید

```bash
finch create
```

اگر بدون flag اجرا شود، `finch create` به‌صورت تعاملی نام پروژه و اینکه آیا از Docker استفاده شود یا نه را می‌پرسد. بقیه موارد مقدار پیش‌فرض منطقی دارند: پروژه در دایرکتوری‌ای هم‌نام پروژه ساخته می‌شود، و قالب به‌صورت پیش‌فرض `simple` است مگر اینکه با `-t`/`--template` آن را تغییر دهید. برای رد کردن کامل این پرسش‌ها:

```bash
finch create -n my_app -p ./my_app -t example -d
```

برای فهرست قالب‌های رسمی موجود برای `-t` (که به‌صورت زنده از GitHub واکشی می‌شوند)، `finch templates` را اجرا کنید. قالب `example` همان پروژه‌ای است که در سراسر این مستندات استفاده شده و شامل نمونه‌های MongoDB، MySQL، SQLite، WebSocket، i18n، فرم‌ها، و مستندات API است؛ `simple` یک نقطه شروع مینیمال است. اگر `-d`/`--docker` را پاس ندهید و به پرسش Docker پاسخ «no» بدهید، فایل‌های `Dockerfile`، `.dockerignore`، و `docker-compose.yaml` پروژه تولیدشده به‌صورت خودکار حذف می‌شوند.

## اجرای پروژه جدید

```bash
cd my_app
dart pub get
finch serve
```

`finch serve` سرور توسعه را همراه با یک file watcher راه‌اندازی می‌کند — فایل‌های widget و زبان به‌صورت خودکار و بدون نیاز به راه‌اندازی مجدد شناسایی می‌شوند. برای تفاوت میان `serve` (توسعه) و یک باینری کامپایل‌شده (production) به [Running an Application](4.run_app.md) مراجعه کنید.

## افزودن Finch به پروژه موجود

```bash
dart pub add finch
```

سپس اجرا کنید:

```bash
dart pub get
```

همچنان باید تنظیمات `lib/app.dart` و یک تابع مسیر (routing) را به‌صورت دستی اضافه کنید — برای ساختار مینیمال آن به [Running an Application](4.run_app.md) مراجعه کنید، چرا که `dart pub add` فقط dependency را اضافه می‌کند، نه ساختار اسکلتی که `finch create` تولید می‌کند.

## به‌روزرسانی Finch

```bash
finch -u
```

این دستور خود Finch CLI فعال‌شده به‌صورت global را به‌روزرسانی می‌کند (معادل اجرای دوباره `dart pub global activate finch`). برای ارتقای dependency **پکیج** `finch` درون یک پروژه، باید از ابزارهای معمول دارت استفاده کنید: `dart pub upgrade finch`.

## مرحله بعد

برای تمام دستورات موجود به [Finch CLI](2.finch_cli.md) مراجعه کنید، یا مستقیماً به [Configuration](3.configuration.md) بروید تا اولین برنامه خود را راه‌اندازی کنید.
